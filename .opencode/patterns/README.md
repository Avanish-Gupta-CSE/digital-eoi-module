# Golden patterns

Start from the matching file. Do not invent a structure. Each pattern names the real file to copy
and the checklist to finish. If your task fits none, ask the Tech Lead before coding.

| Task | Pattern |
|---|---|
| A new button/form that writes | `new-write-endpoint.md` |
| A new form in a JSP | `new-form.md` |
| A new child table (add/delete rows of a report) | `new-child-table.md` |
| A new maker-checker action | `new-workflow-action.md` |
| A test for any of the above | `new-endpoint-test.md` |
